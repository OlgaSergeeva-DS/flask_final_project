# Итоговый проект: Дневник программиста (Flask)

Этот проект представляет собой веб-приложение на Flask с авторизацией и базой данных.

## 🚀 Как запустить
1. Создайте виртуальное окружение: `python -m venv .`
2. Активируйте его: `source Scripts/activate` (для Windows)
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите сервер: `python main.py`
5. Перейдите по адресу: http://127.0.0.1:5000/
